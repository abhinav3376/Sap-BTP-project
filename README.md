# SAP SD – Order to Cash (O2C) Implementation

## Overview

This project implements the **end-to-end Order-to-Cash (O2C) process** in **SAP SD** for a fictional FMCG company *NovaMart*. It covers the full sales cycle from inquiry to payment with integration to **SAP FI and MM** 

## O2C Process Flow

* Inquiry → VA11
* Quotation → VA21
* Sales Order → VA01
* Delivery → VL01N
* PGI → VL02N
* Billing → VF01
* Payment → F-28

## Key Features

* Automated order processing with **ATP & credit check**
* **Real-time inventory & financial integration**
* **GST-based pricing (TAXINN)**
* Centralized customer & material master data

## Tech Stack

* SAP ECC 6.0
* SAP SD, FI, MM
* SAP GUI, SPRO (IMG)

## Results

* Order processing: **45 min → 8 min**
* Billing: **5–7 days → same day**
* Pricing errors: **12% → <0.5%**
